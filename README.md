# Machine Learning Models from Scratch

This project implements the 10 foundational ML models as well as two bonus models. Each folder contains two jupyter notebook files, one with an implementation of the model using a Machine Learning Library, and the other implements the same model using only numpy. 

For the first 9 models I used Sci Kit Learn, and for the neural networks I used PyTorch for their ML Library implementation. In almost all of them I was able to recreate the exact same model and results with the numpy model.

- MODEL  1: Linear Regression "01_linear_regression"
- MODEL  2: Logistic Regression "02_logistic_regression"
- MODEL  3: K Nearest Neighbors "03_knn"
- MODEL  4: Support Vector Machine "04_svm"
- Model  5: Decision Tree "05_decision_tree"
- Model  6: Random Forest "06_random_forest"
- MODEL  7: Naive Bayes "07_naive_bayes"
- Model  8: K Means Clustering "08_k_means_clustering"
- MODEL  9: Principal Component Analysis "09_pca"
- Model 10: Multi-Layer Perceptron "10_mlp"
- MODEL 11: Generative Pre-Trained Transformer "11_transformer"
- Model 12: Universal Function Approximator "12_ufa"
